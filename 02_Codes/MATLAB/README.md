# UKERC LDES

Development repository for the UKERC Long Duration Energy Storage modelling project at the University of Birmingham.

The source code will be made available after publication. 

The following MATLAB scripts and data files will be included in this repository:

| File | Description |
|---|---|
| `Main01_MILP_Model_Input.m` | Main input configuration for the MILP model |
| `MainFun01_MILP_Model_Input.m` | Preparation and processing of MILP model inputs |
| `MainFun02_MILP_Model_Optimization.m` | MILP model optimisation |
| `MainFun03_MILP_Model_Output.m` | Processing and analysis of model outputs |
| `SubFun_CleanSheetData.m` | Data cleaning and preprocessing |
| `SubFun_InitializePara.m` | Initialisation of model parameters |
| `SubFun_Kmeans_Cluster.m` | K-means clustering for data processing |
| `SubFun_MILPInputMatrix.m` | Construction of the MILP input matrix |
| `SubFun_TEA_DataLoad.m` | Loading of techno-economic analysis data |
| `SubFun_TechArrayMap.m` | Technology mapping and classification |
| `TEA_DataLoad.mat` | Techno-economic analysis dataset |
